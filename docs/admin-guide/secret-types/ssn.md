# 🪪 Social Security Number

A US Social Security Number and the name of the person it belongs to.

- The editor takes the number as `123-45-6789` or as nine digits without dashes.

Type id: `type-ssn`. Agents and `sneakers-put` name the type by this id; `sneakers_list_secret_types` lists it.

## 🔒 What's secret {#whats-secret}

**SSN** is masked until someone who can read the secret reveals or copies it, and every reveal and copy is written to the [audit trail](../audit.md). Everything else is plain metadata that anyone who can see the folder can see.

**SSN** is super-sensitive: the reveal shows a partial mask first and takes a second, deliberate reveal for the whole value. Service accounts and personal tokens can't read it while the **Allow API access to sensitive secrets** setting is off, which is the default ([security settings](../security-settings.md)). Checking out a secret of this type asks for a fresh second factor while **Require MFA for sensitive checkout** is on, also the default.
